# 投資題材的覆蓋範圍與 2026-10-11 的刪減

> 相關程式碼:`web/scripts/build-sector-theme-xref.mjs`、`web/src/lib/themeXref.ts`
> 守衛:`web/tests/explore-links.mjs`(`npm run test:explore`)

---

## 為什麼砍:機械衍生的題材不能算「策展」

`/map` 原本有 102 個題材,其中約半數是 `build_themes.py` 由 buzzword 自動展開的,
標題多半長成 `半導體製造｜晶圓代工` 這種「大類｜子類」。
留著它們,就**不能誠實說這份清單是策展的** —— 而頁面不可以說假話。

## 🔴 判準是「是不是手寫的」,不是「標題長什麼樣」

盤點時看到「49 個標題帶『｜』」與「52 個沒有敘事」**幾乎**相同。
那個「幾乎」必須先算清楚,否則會用一個相關性當定義:

| | |
|---|---|
| A = 標題帶「｜」 | 49 |
| B = 沒有敘事 | 52 |
| A ∩ B | 49 |
| **A − B(有「｜」但有敘事 → 會誤砍)** | **0** |
| **B − A(沒「｜」但沒敘事 → 會漏掉)** | **3** |

→ 用「｜」當判準**不會誤砍任何手寫題材**,但會留下 3 個同樣是機械衍生的:
`玻璃基板 Glass Substrate` / `折疊機` / `人形機器人`(都無敘事、無市場規模、三層不齊)。

### 那一個例外:`semi-foundry` 留下來了

`半導體製造｜晶圓代工` 無敘事,但有 **`市場規模: 全球約 US$130B`**、`CAGR: 10%+`、4 項關鍵指標。

`market_size` 是 `build_themes.py` 裡**人工填寫**的策展欄位
(原始碼註解:「Curated metadata … 選填:策展關鍵數字」),
而且**52 個無敘事的題材裡只有這一個有**(有敘事的 50 個裡則有 21 個)。
→ 有人手動填過 → 保留 → **實際刪除 51 個,保留 51 個**。

判準落定為:**無敘事 **且** 無市場規模**。

## 砍之前先量後果(預測),砍之後逐項對照(實測)

| | 砍前 | 預測 | 實測 |
|---|---|---|---|
| 題材數 | 102 | 51 | **51** ✓ |
| 題材覆蓋個股 | 663 | 585 | **585** ✓ |
| 死角(題材與產業鏈皆無) | 179(10.3%) | 187(10.8%) | **187(10.8%)** ✓ |
| `related` 殘留斷鏈 | — | 0 | **0** ✓ |
| `overlap` 殘留斷鏈 | — | 0(42 條會自動消失) | **0** ✓ |
| xref 殘留斷鏈 | — | 0(31 個指向自動消失) | **0** ✓ |

🔴 **「會自動消失」是推論,所以砍完實測確認過,不當成理所當然。**
`related` / `overlap` / xref 都是 `build-map-index` / `build-sector-theme-xref`
依成員重疊**算出來**的,來源檔一刪就不再產生 —— 但那句話要有證據。

### 代價只有 8 檔

```
失去【所有】題材晶片的個股 = 78
  其中仍在產業鏈裡(還探索得到)= 70
  其中變成完全探索不到        =  8
```

產業鏈覆蓋 1,489 檔把缺口幾乎全接住了。死角只從 10.3% 變成 10.8%。

## 三個「沒有」都要說出來,不要靜默消失

砍完之後有三處會落在空集合。原本的寫法都是**整塊不顯示** ——
那在畫面上與「這個功能不存在」沒有差別。

| 位置 | 空集合的規模 | 現在說什麼 |
|---|---|---|
| `/report` 所屬投資題材 | **1,152 檔**(本次新增 78) | 「本站尚未將此標的歸入任何投資題材」+ 連到它的產業價值鏈 |
| `/report` 同上,且無產業鏈 | **187 檔**(本次新增 8) | 同上 + 連到 `/discover` 關鍵字反查 |
| `/sectors/chain/*` 相關投資題材 | **7 個產業鏈**(本次新增 3) | 「目前沒有與此產業鏈重疊達門檻(≥ 2 檔)的投資題材」+ 連到 `/map` 與 `/discover` |

⚠️ 注意那兩組數字的差別:**1,152 與 187 是現況總數,78 與 8 是本次新增。**
前者決定「這段文字會出現在多少頁上」,後者才是這次改動的代價。
兩個都要講,只講一個都會誤導。

本次新增的 3 個產業鏈:**交通運輸及航運 / 自動化 / 金融科技**。
另外 4 個(貿易百貨 / 油電燃氣 / 電子商務 / 文化創意)**砍之前就已經是 0**。

## 怎麼重算

```bash
node web/scripts/build-data.mjs     # 重生 themes-index / map-index / sector-theme-xref
npm --prefix web run test:explore   # 守衛:覆蓋率、門檻、斷鏈、三態文字
```

死角與孤兒的清點(一次性量測腳本,範圍由資料導出):
`universe = reports-index.byTicker` 減去「所有題材成員 ∪ 所有產業鏈成員」。

> ⚠️ 量測腳本和產品程式適用同一條規則:**先把「有哪些區塊」由資料導出**,
> 不要寫死清單 —— 否則漏掉一塊時,它會照樣宣稱「逐項對上」。
